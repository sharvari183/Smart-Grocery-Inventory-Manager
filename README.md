# Smart Grocery Inventory Manager

## Project Overview

Smart Grocery Inventory Manager is a grocery tracking and inventory management system built using Python, Pandas, and Matplotlib in Google Colab. The project helps users manage grocery stock, monitor expiry dates, generate shopping lists, and visualize inventory data.

This project demonstrates inventory management concepts, data analysis, visualization, and file handling.

---

## Problem Statement

Managing grocery inventory manually often leads to:

* Expired products
* Unnecessary purchases
* Low-stock situations
* Food wastage
* Difficulty tracking inventory

This project provides a simple solution for inventory monitoring and grocery planning.

---

## Features

* Add and manage grocery inventory
* Track item quantity
* Low stock alerts
* Expiry date monitoring
* Shopping list generation
* Inventory visualization using graphs
* Category-wise analysis
* Export inventory data to CSV
* Google Colab compatible
